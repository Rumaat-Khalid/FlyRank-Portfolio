# How to Add a New Case Study

All case studies will be stored in the `Case-Studies/` folder of this repository.

## Steps to Add a Case Study

1. Create a new Markdown file inside the `Case-Studies/` folder using a clear project-based filename.
2. Describe the problem or task that needed to be addressed.
3. Explain what I did, including the tools and AI workflows used.
4. Describe the outcome, results, or what I learned.
5. Add relevant evidence such as screenshots, outputs, or links where available.

## Case Study Format

Every case study will follow the same three-part structure:

- **Problem:** What was the task or challenge?
- **What I Did:** What approach, tools, and steps did I use?
- **What Came of It:** What was the result, outcome, or learning?

This structure will keep future case studies consistent, clear, and easy to review.
